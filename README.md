# Portfólio

Este projeto é um portfólio pessoal em HTML, CSS e JavaScript.

## Como executar

Na raiz do projeto, execute:

```bash
python -m http.server 8000
```

Depois abra o navegador em:

```text
http://localhost:8000
```

## Estrutura

- `index.html` — página principal
- `styles.css` — estilos visuais
- `script.js` — comportamento leve da página
